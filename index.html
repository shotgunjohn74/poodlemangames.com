Who we are

Poodleman Games LLC is an independent studio making games for phones and PCs.

We build our games from scratch in C# and MonoGame, so one code base runs on Android, Windows and iOS. Paper Heroes is our first release, and there are more games to come; each one will get its own corner of this site.
